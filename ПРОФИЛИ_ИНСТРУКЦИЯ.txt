WTracker — модификация с профилями (0.1.1-profiles.1)
Оригинальный проект: https://github.com/bmen25124/SillyTavern-WTracker
Лицензия оригинала: MIT (см. LICENSE)

ЧТО ДОБАВЛЕНО
- Configuration Profiles в начале существующей панели настроек WTracker.
- New / Rename / Delete.
- Import JSON / Export JSON целого профиля (промпты, HTML, схемы,
  подключение, авто-режим, ограничения и прочие рабочие настройки).
- Bind selected to this chat / Unbind: закрепить профиль за отдельным чатом.
- При открытии привязанного чата соответствующий профиль активируется автоматически.
- В чатах без привязки используется глобальный профиль по умолчанию.
- Изменения в обычных настройках WTracker автоматически записываются в текущий профиль.

ПЕРЕД УСТАНОВКОЙ
1. СДЕЛАЙТЕ КОПИЮ действующей папки WTracker и по возможности
   резервную копию настроек SillyTavern и чатов.
2. Не устанавливайте рядом вторую копию этого же расширения с другим
   именем папки: могут появиться два обработчика и двойные запросы.
3. Остановите запущенную SillyTavern перед копированием файлов.

УСТАНОВКА ПОВЕРХ ТЕКУЩЕГО WTRACKER (самый щадящий способ)
1. Найдите установленное расширение SillyTavern-WTracker.
   Обычно это data/<имя_пользователя>/extensions/SillyTavern-WTracker
   (путь может отличаться на вашей установке).
2. Используйте архив WTracker_Profiles_PATCH.zip и скопируйте из него
   файлы dist/index.js, dist/style.css и dist/profiles.js в существующую
   папку расширения, подтвердив замену первых двух файлов.
3. При желании замените и manifest.json для отображения версии мода.
4. Запустите SillyTavern и обновите страницу с очисткой кеша (Ctrl+F5).

АЛЬТЕРНАТИВА
WTracker_Profiles_FULL.zip содержит полную папку расширения с исходниками.
Распакуйте ее в папку пользовательских расширений вместо оригинала,
но только после резервного копирования существующей папки.

ИСПОЛЬЗОВАНИЕ
1. Откройте Extensions > WTracker > Configuration Profiles.
2. Профиль "My existing settings" создается автоматически из ваших
   действующих настроек — никаких схем и промптов переписывать не нужно.
3. Нажмите New, чтобы скопировать текущие настройки в новый профиль.
4. Отредактируйте настройки WTracker ниже панели — они сохранятся
   автоматически в выбранном профиле.
5. Откройте конкретный чат и нажмите Bind selected to this chat.
6. При возвращении в этот чат он автоматически загрузит свой профиль.
7. Export JSON сохраняет только настройки данного профиля, не чаты/ключи API.
   Импорт через Import JSON создает новый профиль.
8. Unbind открепляет профиль; чат возвращается к глобальному профилю.

ВАЖНО
- Сохраненный ID профиля подключения — только ссылка на профиль SillyTavern;
  сами API-ключи не экспортируются. После импорта на другой установке
  может потребоваться повторно выбрать Connection Profile.
- Уже сгенерированные плашки WTracker НЕ переписываются при смене профиля.
  Они сохраняют свой HTML внутри соответствующего сообщения, как и раньше.
- При удалении профиля привязки в других чатах станут недействительными:
  когда такой чат откроется, сработает глобальный профиль по умолчанию.
- Если GitHub-обновлятор перезапишет исходное расширение, модификации
  в dist могут исчезнуть. В таком случае повторно установите PATCH.
- Проверены синтаксис JavaScript/TypeScript и логика хранения профилей
  на тестовом окружении. В настоящей пользовательской SillyTavern
  интеграция ещё требует проверки.
- Результат сделан на основе исходников предоставленного ZIP, без
  изменения оригинальной генерации, шаблонов, событий сообщений или стилей
  других элементов. Изменения предназначены только для профилей.
